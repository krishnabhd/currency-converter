# Currency Converter

A simple web app for converting amounts between supported currencies. Enter an amount, select the currencies, and get the converted value using exchange-rate data from the Frankfurter API.

The app also displays country flags for the selected currencies and updates the result when you request a conversion.

## Built with

- HTML
- Tailwind CSS
- JavaScript
- Frankfurter API

## Run locally

Download or clone this repository, then open `index.html` in your browser.

Exchange rates are reference rates and may differ from live market quotes.
